# AI 脚手架流程能力验收

日期：2026-10-22（Asia/Shanghai）。范围为流程工具与 Skill 更新；未创建用户真实站点，未发布或部署。

## 本轮交付

1. 需求与选择：Skill 根据用户需求/当前上下文整理目标、用户、核心流程、不做事项和模块选择；保留 user/context/default 依据和理由。`--plan` 接受经校验的 JSON，生成 `starter.project.json`，同步填入 PROJECT.md 的需求摘要。未提供计划时保留待定，不按关键词启用付费服务。
2. 环境检查：`project:doctor` 检查 Node、pnpm、依赖、本地配置、认证密钥形状、DB、端口及选中模块缺项。输出不包含凭据值，不停止进程或查询远端 secrets；无依赖时也可启动。
3. 恢复与交接：`project:status` 报告初始化、实现与验收状态及下一步；`project:resume` 从固定本地步骤继续，依赖未变时复用安装状态，仍幂等执行本地 setup。保留业务、密钥与验收记录，缺失本产品配置时不自动重置。
4. 业务验收：计划记录步骤、预期、local/provider 范围、local/mock/real 验证和证据。`project:check` 校验格式/证据，`--ready` 还要求无必需待办、存在必需业务用例且通过；基础检查不能代替业务验收，mock 不可通过真实供应商用例。

选择 required 不代表模块已经实现，deferred 也不自动删除源码。运行时配置不从机器计划自动启用。业务实现和实际浏览器操作由 Agent 执行，脚本不调用模型来猜需求。

## 限制

- 上下文判断和按需求编写业务用例依赖执行 Skill 的 Agent；本轮没有独立真实产品的完整业务开发演练。下一步用用户提供的站点验证这些判断是否合适。
- 计划校验验证声明与路径存在，不证明截图内容、测试真实性或业务正确。更改需求/代码后的受影响用例由 Agent 重置；不提供自动语义追踪或无冲突升级。
- 无新增页面或应用运行时改动，本轮未重新执行开发 E2E 或人工页面截图；已执行生成应用的生产浏览器测试。
- 无云端创建、部署、真实登录/发信/支付或模型调用。没有 Git 提交、推送、额外付费或项目依赖变更。
- 构建仍有既有 CSS sourcemap 警告，影响调试映射，不阻碍本轮构建。
